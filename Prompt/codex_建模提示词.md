1. $t=0$ 为警戒雷达发现导弹、控制中心指派任务的时刻；无人机可瞬时完成航向调整。

5. 遮蔽判定（基准模型）：导弹 $m$ 在时刻 $t$ 到真目标中心 $T=(0,200,0)$ 的视线线段被云团 $j$ 遮挡，当且仅当视线线段到云团中心 $C_j(t)$ 的最近距离 $\le 10\,\text{m}$。

7. 起爆点高度必须大于 0；为保证 20 s 下沉期间云团不接地，建议要求起爆高度 $\ge 60\,\text{m}$（即 20 s × 3 m/s）。若某弹无法满足，该弹视为无效并惩罚。
8. 云团对真目标的遮蔽以「云团中心在有效半径内且位于导弹与目标之间」为准；线段距离公式天然包含「位于之间」的条件。

## 5. 物理与几何模型（符号与公式）

### 5.1 符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| $P_{m0},\ u_m$ | 导弹 $m$ 初始位置、单位方向（指向原点） | m, - |
| $v_m = 300$ | 导弹速度 | m/s |
| $U_{k0},\ h_k$ | 无人机 $k$ 初始位置、飞行高度 | m |
| $\theta_k,\ v_k$ | 无人机 $k$ 航向角（水平面）、飞行速度 | rad, m/s |
| $t_{dj},\ \tau_j$ | 第 $j$ 枚弹的投放时刻、引信延时 | s |
| $D_j,\ E_j$ | 第 $j$ 枚弹投放点、起爆点 | m |
| $C_j(t)$ | 第 $j$ 个云团中心 | m |
| $T=(0,200,0)$ | 真目标下底面圆心 | m |
| $R=10$ | 云团有效遮蔽半径 | m |
| $T_{\text{impact},m}$ | 导弹 $m$ 到达假目标时刻 | s |

### 5.2 运动学方程

导弹 $m$：

$$
P_m(t) = P_{m0} + v_m\, t\, u_m, \qquad u_m = -\frac{P_{m0}}{\|P_{m0}\|}, \qquad 0 \le t \le T_{\text{impact},m}.
\tag{1}
$$

无人机 $k$（设初始位置 $U_{k0}=(x_{k0}, y_{k0}, h_k)$）：

$$
U_k(t) = U_{k0} + v_k\, t\, (\cos\theta_k,\ \sin\theta_k,\ 0).
\tag{2}
$$

注意：无人机的 $\theta_k$ 仅为**水平面内**的航向角，飞行高度恒为 $h_k$；“朝向某目标方向飞行”一律取其水平投影方向，例如目标在原点时航向为 $\theta_k = \operatorname{atan2}(-y_{k0}, -x_{k0})$。

第 $j$ 枚弹（由无人机 $k$ 在 $t_{dj}$ 投放）：

$$
P_{sj}(t) = D_j + v_k (t - t_{dj})(\cos\theta_k,\ \sin\theta_k,\ 0)
+ \left(0,\ 0,\ -\tfrac12 g (t - t_{dj})^2\right), \quad t \ge t_{dj},
\tag{3}
$$

其中投放点 $D_j = U_k(t_{dj})$。起爆点与云团中心：

$$
E_j = P_{sj}(t_{dj} + \tau_j), \qquad
C_j(t) = E_j + (0,\ 0,\ -3)\,(t - t_{dj} - \tau_j), \quad t \in [t_{dj}+\tau_j,\ t_{dj}+\tau_j+20].
\tag{4}
$$

### 5.3 遮蔽判定

导弹 $m$ 在 $t$ 时刻到真目标 $T$ 的视线线段为 $[P_m(t),\ T]$。线段到云团中心 $C_j(t)$ 的最近距离：

$$
d_{jm}(t) = \min_{\lambda \in [0,1]} \left\| P_m(t) + \lambda\,(T - P_m(t)) - C_j(t) \right\|.
\tag{5}
$$

解析形式：令 $A=P_m(t),\ B=T,\ C=C_j(t)$，投影参数

$$
\lambda^* = \operatorname{clamp}\!\left(\frac{(C-A)\cdot(B-A)}{\|B-A\|^2},\ 0,\ 1\right),
\qquad d = \left\| C - A - \lambda^*(B-A) \right\|.
\tag{6}
$$

遮蔽条件：$d_{jm}(t) \le 10$。第 $j$ 弹对导弹 $m$ 的遮蔽时间集合：

$$
S_{jm} = \left\{ t \in [t_{dj}+\tau_j,\ t_{dj}+\tau_j+20] \cap [0, T_{\text{impact},m}] : d_{jm}(t) \le 10 \right\}.
\tag{7}
$$

导弹 $m$ 的有效遮蔽时长（多弹取并集）：

$$
T_m = \left| \bigcup_{j} S_{jm} \right|.
\tag{8}
$$

### 5.4 目标函数

- 问题 2：$\max\ T_1$。
- 问题 3 / 4：$\max\ T_1$（多弹并集）。
- 问题 5：$\max\ \sum_{m=1}^{3} T_m$；同时报告 $T_1, T_2, T_3$、三弹同时遮蔽时长、最差导弹遮蔽时长。

## 6. 核心算法

### 6.1 遮蔽时长计算（主算法：粗采样检测 + 二分精化）

对固定的（导弹 $m$，云团 $j$）：

1. 时间窗口取 $[t_0, t_1] = [t_{dj}+\tau_j,\ t_{dj}+\tau_j+20] \cap [0, T_{\text{impact},m}]$；若 $t_1 \le t_0$ 返回空集。
2. 用粗网格 $t = t_0, t_0+\Delta t, \dots, t_1$（$\Delta t = 0.1\,\text{s}$），按式 (6) **全向量化**计算 $d(t)$ 数组。
3. 标记 $d \le 10$ 的连续段。对每段 $[a,b]$：
   - 若 $a > t_0$，用 `scipy.optimize.brentq` 求 $d(t) - 10 = 0$ 在 $[a-\Delta t,\ a]$ 内的根 $a'$；
   - 若 $b < t_1$，用 `brentq` 求 $d(t) - 10 = 0$ 在 $[b,\ b+\Delta t]$ 内的根 $b'$；
   - 若整段延伸到窗口边界，则边界即精确边界。
4. 输出精化后的区间 $[a', b']$（精度 $10^{-6}\,\text{s}$ 量级）。

> 为什么不用纯解析：$d(t)$ 是「点—动线段」距离，其边界满足的方程在中间投影段为四次方程，解析闭式繁琐；粗采样 + `brentq` 在保证 $10^{-6}$ 精度的同时实现简单、鲁棒、向量化友好，是工程上最优选择。若追求完全解析，可用 `numpy.roots` 解对应四次方程后筛选，作为可选的第二实现。

### 6.2 交叉验证算法（稠密采样）

在窗口内以 $\Delta t = 0.005\,\text{s}$ 稠密采样计算 $d(t)$，标记 $\le 10$ 的区间并合并。主算法与稠密采样结果应一致（区间端点误差 $< 0.01\,\text{s}$），用于单元测试与问题 1 回归。

### 6.3 多弹区间合并

对同一导弹的所有弹区间按端点排序后线性扫描合并（标准 interval union），得到 $T_m$。

### 6.4 目标函数封装（约束处理）

```python
def objective(x, problem_id):
    # 1. 解码 x -> 每架无人机的 (theta, v) 与每枚弹的 (t_d, tau)
    # 2. 硬约束（投放间隔、起爆高度、云团接地）用“结构化编码”天然满足，
    #    见 6.5；对仍可能越界的量返回 -inf（或大惩罚）
    # 3. 计算所有弹的 C_j(t)，所有导弹的 P_m(t)
    # 4. 向量化计算各 (m, j) 遮蔽区间 -> 合并 -> T_m
    # 5. 返回 -(T_m 或 sum(T_m))
```

### 6.5 决策变量编码（关键：同机共享航向/速度 + 投放间隔）

变量维度（重要，勿多算）：

| 问题 | 维度 | 变量说明 |
|---|---:|---|
| Q2 | 4 | FY1 的 $\theta, v$ + 单弹的 $t_d, \tau$ |
| Q3 | 8 | FY1 的 $\theta, v$（3 弹共享） + 3×(投放时刻, 引信延时) |
| Q4 | 12 | 3 架无人机 × ($\theta, v, t_d, \tau$) |
| Q5 | ≤ 40 | 5 架 × ($\theta, v$) + 15 弹 × ($t_d, \tau$) |

投放间隔硬约束的编码（同一无人机投放 $n$ 枚弹）：

```python
# 原始决策 u = (u1, ..., un),  ui >= 0
# 排序后投放时刻：
t_d1 = u1
t_d2 = u1 + 1 + u2          # 至少间隔 1 s
t_d3 = u1 + 2 + u2 + u3     # 依此类推
```

这样间隔约束被编码进变量，目标函数连续，DE 更容易收敛。边界建议：$u_1 \in [0, 45]$，其余增量 $u_i \in [0, 8]$；$\theta \in [0, 2\pi)$；$v \in [70, 140]$；$\tau \in [0.5, \tau_{\max}(h_k)]$，其中 $\tau_{\max}$ 由起爆高度 $\ge 60\,\text{m}$ 反推：

$$
\tau_{\max}(h_k) = \sqrt{\frac{2(h_k - 60)}{g}}.
\tag{9}
$$

例：FY1（$h=1800$）约 18.8 s；FY5（$h=700$）约 11.4 s。起爆高度小于 60 m 时直接返回 $-\infty$。

4. 对 M1 用第 6.1 节算法计算遮蔽区间与时长。
5. 输出：遮蔽区间（起止时刻）、遮蔽时长（保留 2 位小数）、投放点/起爆点坐标、云团轨迹。

### 7.2 问题 2（4 维全局优化）

1. 目标：$\max\ T_1$（单弹单区间长度）。
2. 主算法：`scipy.optimize.differential_evolution`（`popsize=20`，`maxiter=800`，`seed=2025`，`tol=1e-8`，`polish=True`，可 `workers=-1` 并行）。
3. 精修：对 DE 最优解做 `SLSQP` / `Nelder-Mead` 局部搜索（容差 $10^{-9}$）。
4. 多起点：Latin Hypercube 或随机取 50–100 个初始点做局部搜索，取全局最优。
5. 可选预扫描：$\theta \times v \times t_d \times \tau$ 粗网格（如每维 8–12 点）生成优质初值。
6. 输出：最优 $(\theta, v, t_d, \tau)$、投放点/起爆点、遮蔽区间与时长、目标历史曲线、3D 轨迹与遮蔽区间图。

### 7.3 问题 3（8 维联合优化）

1. 同机共享：FY1 的 $\theta, v$ 对 3 枚弹一致。
2. 用 6.5 节编码保证投放间隔 $\ge 1$ s。
3. 目标为 3 弹并集时长 $\max\ T_1$。
4. 初始化策略（重要，加速收敛）：
   - 先求单弹最优（问题 2 的解）作为第 1 枚弹初值；
   - 第 2、3 枚弹在单弹最优附近随机扰动，并以「增量并集」为目标做局部优化（贪心）；
   - 将贪心结果拼接为 8 维初值，再整体 DE + 局部精修。
5. 输出 `result1.xlsx`（列规范见 9.2）与遮蔽区间图（三弹并集随时间可视化）。

### 7.4 问题 4（12 维联合优化）

1. 三架无人机（FY1、FY2、FY3）各 1 弹，互不共享变量，无跨机投放间隔约束。
2. 目标：3 弹并集时长 $\max\ T_1$。
3. 初始化：分别用单弹优化（Q2 结构，各 UAV 独立）得 3 组初值拼接；再整体 DE + 局部精修。

### 7.5 问题 5（分层分解 + 全局精修，≤ 40 维）

**阶段 A — 资源分配**：把 5 架无人机的至多 15 枚弹分配给 3 枚导弹。

- 初始方案：按到达时刻与几何位置启发式分配，如 M1 用 FY1/FY4、M2 用 FY2/FY5、M3 用 FY3 及其余，每导弹约 5 枚；
- 随机生成 10–20 种分配方案作为候选，进入阶段 B 后按总目标择优。

**阶段 B — 每导弹独立子问题**：对每个导弹 $m$，把分配给它的弹视为一个「多弹单目标」子问题（结构同 Q3：同机共享航向/速度、同机投放间隔 ≥ 1 s），用 7.3 节方法求解，得局部最优弹道与投放时序。

**阶段 C — 全局协调**：合并三个子问题的解：

- 同一无人机若被分配给多个导弹，其 $\theta, v$ 只能取一个：按「对该 UAV 各弹贡献度加权」贪心选择，或枚举 2–3 个候选；
- 同机投放时刻按 6.5 编码重新排布，保证间隔 ≥ 1 s；
- 计算合并后的总目标，保留最优协调方案。

**阶段 D — 全局精修**：以阶段 C 的完整解为初值（随机扰动 20–50 个副本），整体做 DE（`popsize=10~20`，`maxiter=300~600`，`workers=-1`）+ 局部精修。若预算允许，可把 15 枚弹全部参与（40 维）；否则固定无关紧要的弹只精修关键弹（如各导弹最后 20 s 窗口内起爆的弹）。

**评价指标输出**：

- 每导弹遮蔽时长 $T_1, T_2, T_3$ 与总和 $\sum T_m$；
- 三枚导弹同时被遮蔽的总时长；
- 最差导弹遮蔽时长（稳健性指标）；
- 每枚弹对应的导弹、投放/起爆时刻、投放/起爆点、单弹贡献区间。

输出 `result3.xlsx` 与三导弹遮蔽区间甘特图、5 机轨迹 3D 图。

## 8. 计算优化（性能预算）

### 8.1 优化手段

1. **全向量化**：所有 (导弹, 云团, 时间采样点) 的距离计算用 NumPy 广播一次性完成，禁止 Python 三层循环。
2. **精确区间 + 二分精化**：粗采样只用 0.1 s 网格检测符号变化，边界用 `brentq` 精化；避免 0.005 s 全窗稠密采样（稠密采样仅用于验证）。
3. **窗口剪枝**：每弹只评估 $[t_e, t_e+20]$；每导弹只评估 $[0, T_{\text{impact},m}]$；起爆时刻晚于导弹到达时刻的弹直接跳过。
4. **距离下界快速剔除**：先算「云团中心到导弹视线直线（无限长）的距离下界」与「到导弹/目标两端的距离」，若三者都 > 10 m 直接判定无遮蔽，省去投影与合并。
5. **并行**：DE 种群评估用 `workers=-1`（或 `joblib`）并行；多起点局部搜索并行。
6. **缓存**：同一变量向量在 DE 内不重复求值（DE 本身不重复，但多阶段合并时用字典缓存已算过的完整解目标值）。
7. **数值规范**：全程 `float64`；比较阈值 $10^{-6}$；角度用弧度。

### 8.2 性能预算（参考，单次求解）

| 问题 | 目标评估量级 | 预算 |
|---|---:|---|

## 附录 A：遮蔽区间计算的参考伪代码

```python
import numpy as np
from scipy.optimize import brentq

def dist_to_segment(C, A, B):
    """C, A, B: (N,3) 或 (3,)；返回 C 到线段 [A,B] 的距离。"""
    BA = B - A
    denom = np.einsum("...i,...i->...", BA, BA)
    t = np.einsum("...i,...i->...", C - A, BA) / np.where(denom == 0, 1, denom)
    t = np.clip(t, 0.0, 1.0)
    Q = A + t[..., None] * BA
    return np.linalg.norm(C - Q, axis=-1)

def shielded_intervals(P0, u, T_impact, E, t_e, R=10.0, dt=0.1):
    """导弹 m 与云团 j 的遮蔽区间列表。P(t)=P0+300*u*t; 云团中心 C(t)=E+(0,0,-3)(t-t_e)."""
    t0 = max(0.0, t_e)
    t1 = min(T_impact, t_e + 20.0)
    if t1 <= t0:
        return []
    grid = np.arange(t0, t1, dt)
    P = P0[None, :] + 300.0 * u[None, :] * grid[:, None]
    C = E[None, :] + np.array([0.0, 0.0, -3.0]) * (grid - t_e)[:, None]
    d = dist_to_segment(C, P, T_TARGET)          # T_TARGET = (0,200,0)
    active = d <= R
    if not active.any():
        return []
    out = []
    idx = np.flatnonzero(active)
    start = idx[0]
    prev = idx[0]
    for i in idx[1:]:
        if i > prev + 1:                         # 区间断开
            a, b = grid[start], grid[prev]
            if start > 0:   a = brentq(lambda tt: dist_to_segment(
                E + (0,0,-3)*(tt-t_e), P0 + 300*u*tt, T_TARGET) - R,
                grid[start-1], grid[start])
            if prev < len(grid)-1: b = brentq(lambda tt: dist_to_segment(
                E + (0,0,-3)*(tt-t_e), P0 + 300*u*tt, T_TARGET) - R,
                grid[prev], grid[prev+1])
            out.append((a, b))
            start = i
        prev = i
    a, b = grid[start], grid[prev]
    if start > 0: a = brentq(...)                # 同上
    if prev < len(grid)-1: b = brentq(...)
    out.append((a, b))
    return out
```

> 说明：伪代码中的 `brentq` 边界处理与向量化细节以最终实现为准；务必对 `active` 全部为 True（整个窗口遮蔽）与边界恰好在 0/20 s 处的情况做单元测试。
